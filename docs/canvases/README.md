# Cursor canvases (repo copies)

Cursor only compiles `.canvas.tsx` from `~/.cursor/projects/<slug>/canvases/`.
These files are copies so Continuum / fly-to-surface QA canvases travel with `snds/legion`.

Live files stay in `~/.cursor/projects/Users-snds-Projects-Legion/canvases/`.
The workspace vault does **not** track these (they belong here, not in `snds/workspace`).
